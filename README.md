# Snake Game in C++

A simple console-based Snake Game developed using C++. The game is designed to demonstrate basic programming logic, movement mechanics, and console-based interaction.

---

## 🎮 Features
- Basic snake movement using keyboard input
- Food collection system
- Score tracking
- Collision detection (walls/self)
- Simple game loop
- Restart and exit options

---

## 🛠 Technologies Used
- C++
- Windows Console API
- Basic game logic implementation

---

## 📚 Concepts Practiced
- Arrays  
- Loops  
- Functions  
- Conditional statements  
- Basic game loop design  
- Keyboard input handling  

---

## 🎮 Controls
- W → Move Up  
- S → Move Down  
- A → Move Left  
- D → Move Right  
- X → Exit Game  

---

## 📌 Note
This version uses WASD keys for movement instead of arrow keys due to basic console input handling limitations.
